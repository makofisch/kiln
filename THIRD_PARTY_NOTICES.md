## What is in this repository

The repository contains no third-party code, fonts, 3D models, textures or sounds.

| Files | Origin |
|---|---|
| `src/`, `scripts/`, `blender/*.py` | Kiln's own code (MIT) |
| `build/icon.ico`, `build/icon.png` | Drawn by `scripts/make-icon.mjs` from the mark in `src/shared/brand.ts` (Kiln's own work, MIT) |
| `docs/fixtures/layout-reference/` | Generated by `make_fixture.py` in that folder (Kiln's own work, MIT) |

The UI uses the fonts already on the PC (Segoe UI, Cascadia Code, Consolas); no font files are bundled.

## What Kiln uses but does not ship

- **Blender** (GNU GPL v3 or later; https://www.blender.org/about/license/) is installed by you. Kiln starts it
  headless and runs the scripts in `blender/` inside it. Those scripts are MIT-licensed, which is compatible with
  the GPL that Blender's Python API comes under. Blender bundles **NumPy** (BSD-3-Clause), which the scripts use.
- **Reference images.** The optional research feature (Settings → General → Reference research) downloads images
  into a project's `refs/` folder: openly licensed ones from Openverse and Wikimedia Commons, or images from web pages
  the copilot found. Each image's source, license and creator, where known, are written to `refs/sources.txt`.
  The images are references for you while you model, and they stay on your PC. They aren't part of Kiln, and
  their licenses vary.
- **Roblox.** Kiln can export models for Roblox. It isn't affiliated with or endorsed by Roblox Corporation.
  "Roblox" and "Roblox Studio" are trademarks of their owner.
- **Claude.** "Claude" and "Claude Code" are trademarks of Anthropic PBC. Kiln isn't made or endorsed by Anthropic.
